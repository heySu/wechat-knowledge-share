# Agent 学习笔记 · 公众号连载（七期）

配合本仓库自带的「每日图文」渲染器，把 Markdown 源稿生成为公众号可直接粘贴的排版稿。

## 目录说明

| 文件 | 用途 |
| --- | --- |
| `source-0X.md` | 源稿，用 `::: 01 / 认知` 这类标记分节，是唯一需要手改的文件 |
| `学习笔记-*.md` | 成稿，可直接粘贴到后台「知识库」的正文 |
| `preview-0X.html` | 排版预览，浏览器打开后全选手机列，复制粘贴进公众号编辑器（行内样式会一起带过去） |
| `封面-0X.png` | 2.35:1 头条大图封面 |
| `封面-0X-方.png` | 1:1 次条 / 分享卡片封面 |
| `build.mjs` | 源稿 → 预览页 + 成稿 |
| `import.mjs` | 把七期幂等写入 `data/db.json`（同名条目走更新，不重复插入） |
| `check.mjs` | 核对入库结果：条目数、状态、缺失 id |
| `covers.py` | 生成封面，依赖 Pillow 与系统字体（微软雅黑） |

## 用法

```bash
# 改完 source-0X.md 之后，重新生成预览与成稿
node content/agent-notes/build.mjs

# 写进知识库（会先备份 db.json）
node content/agent-notes/import.mjs

# 核对
node content/agent-notes/check.mjs

# 重出封面
python content/agent-notes/covers.py
```

`data/` 在 `.gitignore` 里，所以知识库数据不会进版本库；这里只保存源稿与产物。

## 写作约定

- 每期六个小节，编号 `01 / 认知`、`02 / 机制` 这种两字分类，与 `publisher.js` 的输出格式一致。
- 代码块宽度控制在 40 列以内——公众号手机端正文宽约 348px，超了会横向溢出。
- 结尾固定三段：今日三句话 / 明日预告 / 互动关键词。
- 封面文案压在左侧安全区，方形裁切不会切到字。
